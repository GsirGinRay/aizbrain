THE PROBLEM

Your context is trapped in one chat window.

AI didn’t get worse when you switched. It just can’t see what you told the last one.

Today

  • Limit reached, so you re-explain everything to another AI
  • Rules and prompts scattered across chat histories
  • No record of what the AI did or what comes next

With AIzBrain

  • Any AI opens the folder and already knows today’s priority
  • Rules live in one file, read by every tool
  • Each AI leaves a work log: done, result, next
HOW IT WORKS

Three plain files do the handoff.

01

Set up a folder

One command, or a few clicks in the app. Entry files point every AI tool at the same rules.

$ npx aizbrain init
+ .ai/INSTRUCTIONS.md
+ .ai/INDEX.md
+ CLAUDE.md  AGENTS.md
+ GEMINI.md  QWEN.md
02

AI starts with context

At session start, a hook hands the AI today’s most important task and the recent handoffs.

# .ai/INDEX.md
Most important today (P1):
Finish the launch post

Recent AI handoffs
Claude Code → next: tighten intro
03

AI writes back

When an AI edits your folder but forgets the log, the hook reminds it once. The next AI reads it.

- Done: drafted the launch post
- Result: Knowledge/Launch post.md
- Next: tighten the intro

Questions

Windows says “protected your PC”. Is it safe?

Windows shows this for new apps without a paid code-signing certificate. Click More info, then Run anyway; you only see it on first install. On a Mac, use System Settings → Privacy & Security → Open Anyway. Updates are checked against a public key built into the app, and all the source code is on GitHub.

Do I need the desktop app for the AI handoff?

No. npx aizbrain init sets up a folder with Node.js alone. The app adds the calendar, board, notifications and phone inbox on the same files.

Can ChatGPT on the web read my folder?

No, a web chat can’t see files on your computer. Use a tool that can, such as Codex, Claude Code or Gemini CLI, or connect a client through the MCP server.

Does it read my AI conversations?

No. Hooks read only your folder, never the conversation. Your AI provider’s own privacy terms still apply to whatever that tool reads.

Can I use it with Obsidian?

Yes. Repeat rules and similar tokens follow Obsidian Tasks, and the same folder can be open in both.
