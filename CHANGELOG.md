# Changelog

Older versions are on the [releases page](https://github.com/GsirGinRay/aizbrain/releases).

## 0.9.6 (2026-11-02)
- No changes to the app. The website and README now cover local files and the one-task-a-day habit.

## 0.9.5 (2026-11-02)

- New `aizbrain` command: `npx aizbrain init` sets up an AI-handoff folder without the desktop app, with hooks and an MCP server.
- New website at [aizbrain.com](https://aizbrain.com).
- English interface: the remaining Chinese is gone from status and error messages, dialogs, the calendar, routine template and task labels.
- English vaults: prompts under `Prompts/` are counted and exported, imports land there, and a new inbox gets an English heading.

## 0.9.4 (2026-10-27)

- Updating from an old Second Brain Workspace install keeps your Start menu and desktop shortcuts.
- Reminder and folder-picker text no longer assumes Windows.

## 0.9.3 (2026-10-26)

- AIzBrain runs on Mac, on Apple Silicon and Intel, with the phone inbox and automatic updates.

## 0.9.2 (2026-10-26)

- The sidebar shows AIzBrain in English and 第二大腦 in Chinese.
- The phone inbox keeps Send on screen at large text sizes and updates itself when you return to it.

## 0.9.1 (2026-10-25)

- Tasks an AI ticks off appear under Done today.
- The AI index understands work logs written on one line.

## 0.9.0 (2026-10-25)

- Renamed to aizbrain, the second brain you share with every AI. Folders and settings stay the same.
- AI handoff gains "write back when you finish", recent handoffs in `.ai/INDEX.md`, and `GEMINI.md` and `QWEN.md` entry files.
- New folders are named in the interface language (`Inbox`, `Projects`, `Knowledge` in English).
- `--aizbrain-hook` installs hooks for Claude Code, Codex, Grok Build and Antigravity.
